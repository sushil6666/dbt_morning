{% docs pii_warning %}
Contains personally identifiable information (PII). Access should be limited to approved users and downstream models should avoid exposing this field unless there is a clear business need.
{% enddocs %}

{% docs ticket_price_definition %}
Ticket price before in-park spend is added. This field represents the ticket component of a visit or sale and should not be interpreted as total visit spend.
{% enddocs %}

{% docs loyalty_points_derivation %}
Loyalty points are derived from membership tier and customer activity. In this project, higher tiers receive higher point allocations, and non-qualified records default to the lowest applicable point value based on the model logic.
{% enddocs %}

{% docs business_season_definition %}
Business season is a project-defined seasonal classification used for reporting and segmentation. It is a business label, not a calendar standard, so downstream consumers should use it consistently with the project’s transformation logic.
{% enddocs %}

{% docs surrogate_key_note %}
Surrogate key generated by dbt for stable uniqueness across one or more business fields. It is intended for joins and model identity, not for business-facing reporting.
{% enddocs %}

{% docs discount_category_definition %}
Discount category is the normalized label describing the type of discount applied to a ticket or sale. It groups raw discount behavior into consistent reporting buckets.
{% enddocs %}

{% docs fear_level_mapping %}
Fear level is a normalized classification of scare intensity used for haunted attractions and related analytics. The mapping standardizes source values into a consistent set of reporting categories.
{% enddocs %}
